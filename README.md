# Budget Buddy
A simple CLI app that enables budgeting and expense tracking based on the envelope system.


## Features
- One main account, multiple envelopes
- Create a budget using envelopes
- Add transactions and track expenses
- Automatic filling of envelopes


## File Structure
```
budget-buddy/
├── main.py         # main app (menus)
├── storage.py      # storage system
└── utils.py        # utility functions
```


## Getting Started
### Prerequisities
- Python
- Git

### Installation
```
# Clone the repository
git clone https://github.com/self-reliantkid/budget-buddy.git

# Navigate to project folder
cd budget-buddy

# Run the app
python main.py      # Windows
python3 main.py     # MacOS/Linux
```
