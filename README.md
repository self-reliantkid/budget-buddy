## Getting Started
### Prerequisities
- Python 3.11
- Git

### Installation
**Clone the repo**
```
git clone https://github.com/self-reliantkid/budget-buddy.git
```

**Navigate to project folder**
```
cd budget-buddy
```

**Run the app**
```
python main.py      #Windows
```

```
python3 main.py     #MacOS/Linux
```


## Project Structure
